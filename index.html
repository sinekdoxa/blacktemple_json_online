Получить подписку

Ссылка отправляется только указанному серверу подписки. GitHub раздаёт файлы страницы, но не обрабатывает введённую ссылку. Аналитики, CDN и сторонних QR-сервисов здесь нет.

Браузеру необходимо разрешение CORS от сервера подписки. Без него прямой запрос с GitHub Pages невозможен. Прокси не используется. Идентификатор устройства сохраняется локально; очистка данных сайта может создать новый HWID и занять слот устройства.

Открыть ответ из файла / перенести идентификатор

Файл обрабатывается локально. Это исходный ответ подписки, а не уже экспортированный массив Xray.

Импортируйте идентификатор до первого запроса, если нужно сохранить прежний HWID. Не распространяйте его вместе с сайтом. Идентификатор общий для этого сайта в данном браузере, не для всех устройств.

Готово к работе. Введите ссылку или откройте файл.

Конфигурации

JSON — массив отдельных профилей Xray, не универсальный формат для всех клиентов. Если импорт массива не поддерживается, скачайте один профиль или используйте VLESS / QR. Все профили используют SOCKS 127.0.0.1:10808; не запускайте их одновременно без смены портов.

Ссылка и результаты не сохраняются сайтом. Скачанные файлы и QR содержат секреты доступа — не публикуйте их. Сервер подписки видит запрос и ваш IP. Расширения браузера и код опубликованной страницы должны быть доверенными. Работоспособность VPN не проверяется.
